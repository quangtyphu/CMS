Quản Lý Chrome

Proxy SOCKS5: host:port:user:pass. Mỗi profile = Chrome + proxy riêng. Khóa chính = tên thiết bị (bắt buộc, duy nhất). Khi đổi proxy hoặc thiết bị, hệ thống tự đồng bộ sang acc LC79 và xoso66 (theo device và username profile). Username game có thể để trống lúc tạo và cập nhật sau trên bảng. Cột LC79: lưu acc vào game_data.db (accounts + user_profiles, có NickName). Cột Xoso66: đăng ký acc (CMS chỉ bật xoso66_api.py, không chạy main.py). AllGame: lưu acc vào allgame.db — khóa game + username (username có thể trùng giữa các game).
